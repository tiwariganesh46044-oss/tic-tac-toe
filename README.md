# 🎮 Tic Tac Toe — Ultimate Game

A modern, responsive, and interactive Tic Tac Toe game built using HTML5, CSS3, and Vanilla JavaScript.

Enjoy a fun two-player gaming experience with beautiful animations, sound effects, customizable player names, and a statistics dashboard.

## ✨ Features

- 🎯 Two-player Tic Tac Toe gameplay (X and O).
- 🏆 Automatic winner detection.
- 🤝 Draw detection.
- 📊 Live scoreboard.
- 🔄 Restart Game and New Game options.
- 🎨 Dark and Light themes.
- 👤 Customizable player names.
- 🔊 Interactive sound effects with ON/OFF control.
- 📈 Game statistics dashboard.
- 📜 Last 10 games history.
- 🧹 Clear game history.
- 🟢 Animated winning line.
- 🎉 Winner celebration with fireworks, rockets, balloons, and confetti.
- 💾 LocalStorage support for saving game preferences and statistics.
- 📱 Fully responsive design for mobile, tablet, and desktop.
- ♿ Reduced-motion accessibility support.

## 🛠️ Technologies Used

- HTML5

## 🎮 How to Play

1. Enter names for Player X and Player O.
2. Player X starts the game.
3. Players take turns selecting empty cells.
4. Get three matching symbols in a horizontal, vertical, or diagonal line to win.
5. If all nine cells are filled without a winner, the game ends in a draw.
6. Use Restart Game to play another round.
7. Use New Game to start a fresh game.
